# 재생성과 업로드 완료 정리

- 음성 다시 제작은 임시 폴더에서 음성·자막을 완성한 뒤 기존 파일과 음성 조각 폴더를 교체한다. 이전 싱크 보고서도 새 설정에 맞춰 교체하거나 제거한다.
- 본 프로그램에서 최종 영상을 다시 렌더하면 임시 영상이 완성된 뒤 기존 최종 파일을 교체한다. 제작 실패·중단 시 기존 완성 파일은 유지하고 임시 폴더는 제거한다.
- 유튜브 업로드 완료 여부는 자동 감지하지 않는다. 완성 확인 또는 작업 보관함의 **업로드 완료 후 정리**를 누르면 삭제할 경로를 보여준다. 확인하면 해당 작업의 대본·프롬프트·음성·이미지·자막·영상·연결된 업로드 폴더와 문서 백업을 영구 삭제한다.
- 제작 중에는 정리하지 않는다. 다른 작업과 채널 설정·API 키·사용한 주제 기록은 유지한다.
- 새 업로드 패키지는 `제작원본.json`으로 원본 작업과 연결한다. 기존 패키지는 대기열의 원본 연결 정보가 있으면 함께 정리한다. 연결 정보가 없는 오래된 패키지는 해당 업로드 폴더만 삭제하며 확인창에 이 범위를 안내한다.
- 자동 검증은 임시 파일과 모의 생성 결과만 사용한다. 실제 사용자 작업 삭제나 유료 재생성은 검증 목적으로 실행하지 않는다.

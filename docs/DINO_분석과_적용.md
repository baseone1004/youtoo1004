# DINO V13.1 분석과 적용

분석 대상: 사용자 제공 `DINO_V13_1_사용자배포_통합설정_20261008.zip` (2026-10-09).
실행 파일은 실행하지 않았다. ZIP에 포함된 안내문, 검증 기록과 로컬 음성 정렬·Codex 이미지 연결 소스를 확인했다. 핵심 제작 프로그램은 EXE로 배포되어 전체 구현을 확인할 수 없다. 동봉 검증 결과는 배포자의 보고이며 이 저장소에서 직접 검증한 결과와 구분한다.

## 적용한 기능

| 디노에서 확인한 방식 | 이 프로그램에 적용한 기능 |
| --- | --- |
| 작업 보관함과 생성 미디어 보존 | 작업 보관함에 대본·음성·장면 수·완성 영상·업로드 패키지를 함께 표시. 대본이 없어진 자료 폴더도 표시 |
| 제외 작업의 복원 | 별도 로컬 문서 백업에서 없는 대본·프롬프트·자막만 복원. 기존 파일은 덮어쓰지 않음 |
| 편집 전에 누락·중복 파일 검사, MP4 우선 사용 | 연결표의 장면 번호 검사, 같은 번호의 MP4 우선, 누락·중복이면 렌더 시작 차단. 장면_매칭_검사.json 저장 |

문서 자동 백업은 이 저장소에서 새로 구현했다. 시작 시, 문서 저장 전후, 음성 제작 전, 작업 종료 시 백업한다. 경로마다 최신 3개 변경 버전을 유지하고 SHA-256으로 복원 무결성을 확인한다. 위치는 `대본/_상태/문서백업`이다. 프로그램에서 생성한 이미지·음성·영상, 개인 설정·API 키는 백업이나 Git 커밋에 포함하지 않는다. 전체 대본 폴더를 외부에서 삭제하면 같은 폴더 아래 백업도 사라질 수 있으므로 독립적인 외장 백업을 대신하지 않는다.

작업 보관함은 파일을 삭제·이동하지 않는다. 현재 연결표가 없어 장면 검사를 할 수 없는 작업은 연결표·자막 제작을 먼저 안내한다. 편집기 내부에서 직접 시작한 별도 렌더는 편집기 자체 검사를 따르며, 이 검사 차단은 본 프로그램의 자동 제작 렌더에 적용한다.

## 이번에 추가하지 않은 구성

Codex 이미지 연결은 대화 도구를 외부 프로그램에서 자동 호출하는 API가 아니라 사용자가 작업 요청문을 대화에 전달하는 방식이다. 현재 KIE 자동 제작과 실행 방식이 달라 이번 변경에는 포함하지 않았다.

로컬 이미지·Qwen 목소리 모델은 별도 GPU·모델 설치가 필요하다. 디노의 용량·하드웨어 안내는 동봉 문서의 주장으로, 이 PC에서 직접 설치·검증하지 않았다. 드롭샷과 구독 인증은 기존 프로그램의 운영 목적에 필요하지 않아 포함하지 않았다.

원본 디노 코드·실행 파일·개인 설정은 이 저장소에 복사하지 않았다. 확인한 기능의 동작 방식에 맞춰 독립적으로 구현했다.

## 추가 오류 수정과 검증

작업 화면이 보내는 절대 대본 경로와 서버 목록의 상대 경로를 비교하던 오류를 수정했다. 동일한 실제 경로만 허용하며, 목록 외 파일은 계속 거부한다. 음성 재생성 전에 수정한 대본 저장이 실패하면 유료 음성 요청을 제출하지 않는다.

자동 백업 버전 제한·없는 파일 복원·기존 파일 보존·경로 이탈 차단·백업 변조 거부·MP4 우선·누락·중복·짧은 장면 목록·업로드 패키지 표시·절대/상대 경로를 모의 응답과 임시 파일로 검증했다. 자동 테스트 140개가 통과했으며, 자동 테스트에서는 유료 API를 호출하지 않았다. 실제 저장 작업의 184개 장면 매칭도 확인했다.

브라우저의 음성 재생성 버튼 확인 과정에서 예상과 달리 실제 음성 생성이 시작되어 즉시 중단 요청을 보냈다. 작업은 취소 오류로 종료되었으며 기존 완성 나레이션 파일은 유지되었다. 중단 전에 일부 Inworld 사용량이 발생했을 수 있다. 이 실행을 의도적인 유료 검증 성공으로 보고하지 않는다.

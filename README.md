# 유튜브 영상 자동 제작

주제만 고르면 **대본 → 나레이션 → 이미지 → 썸네일 → 최종 영상**까지 자동으로 만들어 주는 프로그램입니다.
(심리해독소 / 민담·야담 채널용)

## 1. 처음 설치 (한 번만)

1. Python 설치: https://www.python.org/downloads/ 에서 받아 설치할 때 **Add python to PATH** 를 꼭 체크하세요.
2. 이 폴더의 `설정.example.json`을 복사해서 이름을 `설정.json`으로 바꾸세요.
3. `유튜브_자동화_시작.vbs`를 더블클릭하면 크롬에 화면이 열립니다. (처음에는 필요한 프로그램을 설치하느라 1~3분 걸릴 수 있습니다)
4. 화면 오른쪽 위 **⚙ 설정**에서 위에서부터 순서대로 저장하세요.
   - 대본을 쓰는 AI (딥시크 웹은 무료) 와 API 키
   - 나레이션 목소리 (인월드)
   - 드롭샷 이미지 생성 좌표 (6초 좌표 잡기)
   - 내 유튜브 채널 주소 — 이미 올린 영상과 겹치는 주제는 추천 목록에서 자동으로 빠집니다
   - 유튜브 API 키(선택) — 넣으면 조회수·게시일까지 읽어 **내 채널 분석**(잘 된 영상·키워드)을 보여 주고, 새 주제 추천에 반영합니다
   - 텔레그램 알림 (선택)

## 2. 영상 만들기 (매번)

화면 위쪽의 4단계를 순서대로 따라가면 됩니다.

| 단계 | 할 일 |
|---|---|
| ① 주제 고르기 | 채널을 고르고 추천 주제를 체크하거나 직접 적어 추가합니다. **🔄 새 주제 추천**을 누르면 안 본 주제를 보여 주고, 다 보면 AI가 새 주제를 만듭니다. 여러 개를 체크하면 순서대로 만들어집니다. |
| ② 제작 시작 | 그림체를 고르고 **🚀 제작 시작**을 누릅니다. |
| ③ 진행 상황 | 기다리기만 하면 됩니다. 이미지 생성 중에는 마우스·키보드를 쓰지 마세요. |
| ④ 완성 확인 | 썸네일과 유튜브 제목·설명·태그를 복사하고, 결과 폴더의 `최종.mp4`를 올리면 끝입니다. |

완성된 파일은 `업로드/채널이름/날짜_제목/` 폴더에 한곳에 모입니다.

## 3. 그 밖의 기능

- **고급 기능** 메뉴: 이미지 하나씩 다시 만들기, 자막 글꼴·색 설정, 대본·나레이션·썸네일만 따로 만들기, 지침 수정, 작업 초기화
- 콘솔 창을 보며 실행하려면 `유튜브_자동화_시작.bat`를 쓰세요.
- 실행 오류는 `로그_시작.txt`, 화면 오류는 `로그_대본선택.txt`에 남습니다.
- 영상 편집프로그램은 이 폴더, 상위 폴더, 다운로드, 바탕화면의 `편집프로그램/app.py`를 찾습니다. 다른 곳에 있으면 `YOUTUBE_EDITOR_DIR` 환경 변수에 폴더를 지정하세요.

## 개발자 참고

- 화면: `화면/index.html`, `화면/style.css`, `화면/app.js` (서버 `대본선택.py`가 `/`와 `/static/`으로 제공)
- 백엔드 API: `대본선택.py` (8766) · 영상 편집프로그램 (8765)
- 썸네일 문구 합성: `썸네일_합성.py` (심리해독소 = 키워드 강조형, 숫자가 있으면 숫자 배지형, 민담 = 하단 띠형 + 붓글씨)
- 새 주제 추천(AI): `주제_추천.py` → `추천_추가.json`에 누적
- 유튜브 공식 API: `유튜브_API.py` (API 키가 있으면 조회수·게시일까지)
- 내 채널 제목 연동: `채널_연동.py` (yt-dlp로 제목만 읽어 `대본/_상태/채널_제목.json`에 저장, 6시간마다 갱신)
- 테스트: `python -m unittest discover tests`
- `설정.json`에는 API 키가 들어가므로 GitHub에 올리지 마세요. `.gitignore`가 이 파일과 생성 결과물을 제외합니다.

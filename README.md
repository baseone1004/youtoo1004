# 유튜브 영상 자동 제작

주제만 고르면 **대본 → 나레이션 → 이미지 → 썸네일 → 최종 영상**까지 자동으로 만들어 주는 프로그램입니다. 외부 편집기 폴더 없이도 KIE 이미지 생성과 내장 FFmpeg 렌더링을 사용할 수 있습니다.
한국어·일본어 영상은 최소 25분을 유지합니다. 새 정보형 제작은 연속 문장을 글자 수에 맞춰 묶어 이미지 **최대 150장**으로 만듭니다. 150문장보다 짧은 대본은 불필요하게 그림을 늘리지 않습니다. 장면 구성을 저장해 이어 만들기에서도 같은 번호를 사용하고, 이미 프롬프트나 이미지가 있는 기존 제작은 이전 번호를 유지합니다. 음성·자막은 줄이지 않으며 `문장플로우.txt`의 문장별 자막 범위를 `플로우.txt`의 이미지별 범위로 연결합니다. 앞 5장 영상화와 채널별 화풍은 유지합니다.
(심리해독소 / 민담·야담 채널용)

## 1. 처음 설치 (한 번만)

1. Python 설치: https://www.python.org/downloads/ 에서 받아 설치할 때 **Add python to PATH** 를 꼭 체크하세요.
2. 이 폴더의 `설정.example.json`을 복사해서 이름을 `설정.json`으로 바꾸세요.
3. `유튜브_자동화_시작.vbs`를 더블클릭하면 크롬에 화면이 열립니다. (처음에는 필요한 프로그램을 설치하느라 1~3분 걸릴 수 있습니다)
4. 화면 오른쪽 위 **처음 설정**에서 위에서부터 순서대로 저장하세요.
   - 대본을 쓰는 AI (딥시크 웹은 무료) 와 API 키
   - 나레이션 목소리 (인월드)
   - KIE AI API 키 — Z-Image 이미지 생성과 선택한 영상 변환에 공통 사용. 프로그램의 `설정.json`에 저장되며 화면에는 저장된 키를 다시 표시하지 않습니다.
   - 내 유튜브 채널 주소 — 이미 올린 영상과 겹치는 주제는 추천 목록에서 자동으로 빠집니다
   - 유튜브 API 키(선택) — 넣으면 조회수·게시일까지 읽어 **내 채널 분석**(잘 된 영상·키워드)을 보여 주고, 새 주제 추천에 반영합니다
   - YouTube 업로드(선택) — Google Cloud에서 YouTube Data API v3를 사용 설정하고 OAuth 클라이언트를 **데스크톱 앱**으로 만든 뒤 JSON을 [설정 → YouTube 업로드 로그인]에서 등록합니다. 각 저장 계정마다 Google 로그인을 한 번씩 연결하면 완성 패키지를 직접 업로드할 수 있습니다. 기본 공개 범위는 비공개이며, 롱폼과 생성된 쇼츠를 함께 보내도록 선택할 수 있습니다.
   - 텔레그램 알림 (선택)

딥시크 웹 연결 확장을 이미 설치한 컴퓨터에서 프로그램을 업데이트했다면 Chrome의 `chrome://extensions`에서 **대본 만들기 · 딥시크 웹 연결**의 새로고침 버튼을 한 번 누르세요. 새 확장(1.1.0)은 작업 소유자를 확인해, 오래된 탭의 늦은 답변이 현재 작업을 덮어쓰지 못하게 합니다. 새로고침 전 구버전도 최초 작업에는 호환됩니다.

## 2. 영상 만들기 (매번)


간편 화면의 주제 선택 → 제작 시작 → 완성 확인 순서로 따라가면 됩니다.

| 단계 | 할 일 |
|---|---|
| ① 주제 고르기 | 채널을 고르고 추천 주제를 체크하거나 직접 적어 추가합니다. **🔄 새 주제 추천**을 누르면 안 본 주제를 보여 주고, 다 보면 AI가 새 주제를 만듭니다. 여러 개를 체크하면 순서대로 만들어집니다. |
| ② 제작 시작 | **🚀 제작 시작**을 누릅니다. |
| ③ 완성 확인 | 썸네일과 유튜브 제목·설명·태그를 복사하고, 결과 폴더의 `최종.mp4`를 올리면 끝입니다. |

완성된 파일은 `업로드/채널이름/날짜_제목/` 폴더에 한곳에 모입니다. 업로드 연결을 설정했다면 **작업 보관함 → YouTube 업로드**를 눌러 패키지를 전송할 수 있습니다. 공개·일부공개는 버튼을 누를 때 직접 확인을 거칩니다. 전송이 끊겨 YouTube 수신 여부가 불확실한 파일은 자동 재전송하지 않습니다. YouTube Studio에서 해당 영상이 없는 것을 확인한 경우에만 업로드 버튼에서 재시도를 승인하세요. 전송 기록은 패키지 폴더에 저장됩니다.

기본 제작 설정은 롱폼 한 편당 쇼츠 2편입니다. 업로드 패키지에는 최종 영상·자막·썸네일·생성된 쇼츠가 모입니다. 쇼츠가 2편 미만이면 보관함에서 **쇼츠 복구용 대본 선택**을 눌러 원본 대본을 다시 선택한 뒤 이어서 제작하세요. 쇼츠 포함 업로드는 정확히 2편이 준비됐는지 확인하며, 부족하면 롱폼만 올리거나 쇼츠부터 완성하도록 안내합니다.

### 일본어 채널 목소리와 자막

1. 운영할 채널을 선택하고 **제작 언어 → 일본어**로 설정하세요. 채널 이름·소개는 고급 설정의 채널 프로필에서 바꿀 수 있습니다.
2. **처음 설정 → 나레이션 → 일본어 채널**에 Inworld의 일본어 지원 목소리 ID와 속도를 넣고 저장하세요. 일본어 목소리가 비어 있으면 한국어 목소리를 대신 사용하지 않습니다.
3. 일본어 제작은 **Inworld TTS 2**를 사용하고 문자별 타임스탬프로 자막을 생성합니다. 음성을 합칠 때 타임스탬프 기준의 앞뒤 무음을 유지해 시간을 맞춥니다.
4. 생성 후 시간 역전·겹침·음성 길이 초과를 자동 검사합니다. 완성한 작업을 선택한 뒤 **자막 싱크 확인**을 눌러 다시 검사할 수도 있습니다. 기존 자막은 쉼·글자 수로 계산한 추정 방식임을 따로 표시합니다.

목소리·속도·언어 설정을 바꾸면 새 설정으로 음성을 만듭니다. 일본어 자막은 Windows에 Yu Gothic이 설치되어 있으면 해당 글꼴로 렌더합니다. 자동 시간 검사는 발음과 의미에 대한 청취 검사를 대신하지 않습니다. 개발 테스트는 API 모의 응답과 로컬 시험 음성을 사용하며 유료 생성은 실행하지 않습니다.

한국어 제작은 음성 생성 전에 숫자·단위를 낭독 표기로 바꿉니다(5가지 → 다섯 가지, 3명 → 세 명, 30% → 삼십 퍼센트, 2.5배 → 이 점 오 배). 음성과 자막에 같은 표기를 적용하고 일본어에는 이 변환을 적용하지 않습니다. **나레이션 다시 생성**은 같은 대본이어도 음성을 새로 요청하므로 Inworld 사용량이 듭니다. **이어 만들기**는 같은 문장·목소리의 부분 음성을 재사용합니다. 표기가 이미 올바른데 잘못 읽는 경우는 모델의 발음 문제일 수 있으므로 새 음성을 들어 확인하세요.

## 3. 지침 (AI에게 주는 규칙)

- 정보형 채널 대본: `지침/정보형_대본지침.txt` — 아홉 구간 나레이션, **25분 이상 롱폼만**. 제목·설명·태그는 [설정 → 채널 프로필 → 제작 언어]에서 고른 한국어·영어·일본어·스페인어·중국어로 생성됩니다. 채널 이름·소개·마스코트도 프로필만 바꾸면 됩니다.
- 이야기형 채널 대본: `지침/민담/01_기획_지침.txt` → `02_챕터_지침.txt` + `motif_bank.txt`(이야기 씨앗)·`name_bank.txt`(이름)·`참고_*.txt`
- 이미지 프롬프트: `지침/이미지지침_정보형.txt`(현대 배경·마스코트) / `지침/이미지지침_이야기형.txt`(조선 배경·신분별 옷차림). 대본의 채널에 맞는 것을 자동으로 씁니다.
- 썸네일: `지침/썸네일_지침.txt`, 제목·설명·태그: `지침/알고리즘_최적화_지침.txt`
- 모든 지침은 이 프로그램용으로 직접 쓴 것이며 화면에는 나오지 않습니다. 고치려면 `지침/` 폴더의 파일을 메모장으로 열어 수정하세요. 채널(정보형/이야기형)에 맞는 대본·이미지 지침은 자동으로 골라 씁니다.

## 4. 그 밖의 기능

- **고급 편집**: 이미지 하나씩 다시 만들기·이어서 만들기, 앞 5장면 영상 변환, 자막 글꼴·색 설정, 썸네일 다시 만들기, 이 작업 휴지통으로 / 전체 초기화
- 기본 제작은 정지 이미지와 나레이션으로 완성합니다. **Codex로 제작하기**를 켜면 장면·썸네일 이미지는 Codex가 만들고 KIE 영상 변환은 선택한 대본의 첫 5장면까지만 가능합니다. KIE 이미지 모드를 선택한 경우에는 이미지 생성에도 KIE 크레딧이 사용됩니다. 영상 변환에는 별도 KIE 크레딧이 들며, 실패하면 정지 이미지로 계속 편집합니다.
- 이미지가 만들어지는 중에 **다시 만들기**를 누르면 예약되어, 남은 장면을 다 만든 뒤 그 장면을 새로 만듭니다 (제작은 그때까지 다음 단계로 넘어가지 않습니다).
- 콘솔 창을 보며 실행하려면 `유튜브_자동화_시작.bat`를 쓰세요. (대본만 만들기·벤치마킹 등은 모두 화면 버튼으로 실행합니다)
- 휴지통(`대본/_휴지통`)은 30일 지난 항목을 시작할 때 자동으로 지우고, 파일 메뉴에서 바로 비울 수도 있습니다.
- 실행 오류는 `로그_시작.txt`, 화면 오류는 `로그_대본선택.txt`에 남습니다.
- 영상 편집프로그램은 이 폴더, 상위 폴더, 다운로드, 바탕화면의 `편집프로그램/app.py`를 찾습니다. 다른 곳에 있으면 `YOUTUBE_EDITOR_DIR` 환경 변수에 폴더를 지정하세요.

## 이미지 제작 방식과 간편 화면

- **주제 선택 → 제작 시작 → 완성 확인** 순서로 사용하세요. 처음 설정은 대본 AI → 인월드 나레이션 → KIE API 키 순서입니다.
- **Codex로 제작하기**에서는 장면 이미지와 썸네일 이미지를 Codex 이미지 도구로 만듭니다. 이 모드에서 KIE는 선택한 대본의 첫 5장면 영상 변환에만 사용됩니다. Codex 계정 한도와 KIE 영상 크레딧은 각각 적용됩니다.
- KIE 이미지 모드를 선택하면 레퍼런스를 켰을 때 기본 `qwen/image-edit`, 끄면 `z-image` 모델을 사용합니다. 기본 비율은 16:9이고 이미지 생성에도 KIE 크레딧이 사용됩니다.
- 캐릭터는 채널 프로필의 외형·색상 설명과 이야기 인물표를 공통 사용합니다. Z-Image에는 참조 이미지를 보내지 않습니다. 레퍼런스 모델을 사용해도 정확한 외형 일치를 보장하지 않습니다.
- 중단하거나 연결이 끊겼으면 **고급 편집 → 빠진 장면 이어서 만들기**를 누르세요. `.kie-image-tasks.json`의 작업 ID로 기존 KIE 작업을 확인하고 완성된 장면은 건너뜁니다. 원격에서 이미 접수된 작업은 중단 후에도 크레딧이 사용될 수 있습니다.
- 요청 접수 응답을 받지 못한 경우 자동 재결제하지 않습니다. KIE 작업 내역을 확인한 뒤 **고급 편집 → 이미지 → KIE 작업 기록 복구**에서 작업 번호를 연결하세요. 접수되지 않았음을 확인한 경우에만 새 요청을 허용하세요.
- 업데이트 후 실행기를 다시 켜야 별도 편집기에 새 연결이 설치됩니다. `편집프로그램_ZImage_연결.py`가 저장소의 `kie_imagegen.py`를 설치하며 배포판에도 같은 연결을 적용합니다.
- API 문서: [Z-Image](https://docs.kie.ai/market/z-image/z-image), [작업 조회](https://docs.kie.ai/market/common/get-task-detail).

### 중단 후 이어 만들기
- 프로그램 재실행 시 미완료 대기열은 일시정지 상태로 복구됩니다. 화면의 **이어 만들기**를 눌러 제작을 재개하세요.
- 이미지 재생성 예약과 진행 중인 작업 번호는 이미지 폴더에 저장됩니다. 같은 대본으로 이어 만들면 복구하며 API 키는 기록하지 않습니다.
- 손상된 이미지는 완성으로 건너뛰지 않습니다. 저장된 KIE 작업 번호가 있으면 같은 결과를 다시 내려받습니다.
- 준비 상태는 선택한 채널의 나레이션 설정과 KIE 인증·잔액 조회를 확인합니다. 잔액이 있어도 전체 제작 비용을 보장하지는 않습니다.
- 화면 준비 상태 테스트: `node tests/test_readiness.cjs`

- 편집기 기본 포트(8765)를 다른 프로그램이 사용하면 빈 포트를 자동 선택합니다. 키 저장과 편집기 요청은 제작 화면 서버를 통해 전달합니다.

### 레퍼런스 이미지
처음 설정 → 레퍼런스 이미지에서 채널을 고르고 PNG·JPG·WEBP(10MB 이하)를 선택하세요. 업로드한 이미지는 로컬에 저장되고 다음 이미지 생성부터 적용됩니다. 전체 제작·장면 재생성·썸네일에서 같은 채널의 레퍼런스를 사용합니다.

KIE 이미지 모드에서 레퍼런스 사용을 켜면 선택한 편집 모델(기본 `qwen/image-edit`)에 이미지를 전달하고, 끄면 기존 `z-image` 모델을 사용합니다. 생성 시 해당 모델의 KIE 크레딧이 사용됩니다. Codex 모드에서는 레퍼런스가 Codex 이미지 요청에 포함되며 KIE 이미지 API를 호출하지 않습니다. 이미 완성한 장면은 이어 만들기에서 유지되므로 새 레퍼런스를 적용하려면 장면의 다시 만들기를 사용하세요. 연결 해제는 저장한 파일을 지우지 않습니다. 개인 레퍼런스와 설정은 GitHub와 배포판에 포함하지 않습니다.

공식 API: [Qwen Image Edit](https://docs.kie.ai/market/qwen/image-edit), [Seedream 4.5 Edit](https://docs.kie.ai/market/seedream/4-5-edit), [이미지 업로드](https://docs.kie.ai/file-upload-api/upload-file-base-64).

대본 AI는 딥시크 웹·딥시크 API·제미나이를 지원합니다. 클로드 선택·입력·자동 대체는 제거했습니다.
화면 연결 검증: `node tests/test_reference_ui.cjs`

### 한국·일본 채널 순서대로 제작

별도 작업 창 기능을 제거했습니다. 기본 화면 맨 위에서 채널을 선택하고 한 편씩 제작합니다. 각 채널의 목소리·레퍼런스·썸네일 설정은 계정별로 유지되고, 제작물은 언어별 폴더에 저장됩니다. 진행 중에는 채널을 바꿀 수 없습니다.

레퍼런스 절약 기본값은 `qwen/image-edit`의 `landscape_16_9`입니다. KIE 공식 가격표 기준 장당 2크레딧, 출력 1024×576입니다. 150장은 300크레딧, 200장은 400크레딧이며 썸네일·영상 변환은 별도입니다. 1장만 요청하며 고정 seed를 보내지 않습니다. 설명은 2,000자 이내로 전송합니다. 실제 유료 생성은 테스트에 포함하지 않습니다.

### 음성 오류 복구와 사용량
- 대기열은 한 편을 완료한 뒤 다음 편을 시작합니다. 어떤 단계에서든 실패하면 전체 대기열을 멈추며, **이어 만들기**는 가장 앞의 미완성 편부터 저장된 결과로 재개합니다. 뒤의 편은 **앞 편 완료 후 대기**로 표시하고 이전 오류 기록은 접어서 보관합니다.
- 인월드 통신 실패와 키 오류를 구분합니다. 응답을 잃은 유료 음성 요청은 자동으로 재전송하지 않습니다. 사용 내역을 확인한 뒤 수동으로 이어서 시도하세요.
- 음성·자막 싱크 오류가 발생하면 아직 시작하지 않은 음성 요청과 다음 주제 제작을 멈춥니다. 이미 서버에 보낸 요청은 완료될 수 있습니다.
- 일본어 자막 시간 정보가 잘못된 경우 **이어 만들기**를 누르면 문제·누락 음성을 자동으로 다시 만든 뒤 나머지 제작을 진행합니다. 정상 음성은 재사용하고 문제·누락 부분에만 인월드 사용량이 발생합니다. 문제 묶음은 최대 40자의 짧은 구절로 나눠 복구하고 실제 음성 길이로 자막 시간을 연결합니다. 복구 요청은 보내기 전에 기록합니다. 짧은 구절도 실패하거나 응답을 잃으면 이어 만들기를 다시 눌러도 같은 요청을 반복하지 않습니다. 성공한 복구 구절은 재사용합니다. 목소리·속도·대본이 바뀌어 기존 음성과 맞지 않으면 전체 재생성 여부를 별도로 확인하도록 중단합니다.
- 일본어 설명글은 공감 도입·영상 소개·댓글 안내·일본어 고지·해시태그 순서로 작성합니다. 해시태그 앞에는 빈 줄 세 줄을 두며, 한국 채널의 설명 형식은 유지합니다.

이미지 설명이 그대로 반복되면 유료 요청 전에 중단합니다. 장면 지침에는 이전 장면과 다른 구도·행동을 요청하며, 최근 이미지와 매우 비슷한 결과는 생성 상태와 `.kie-image-review.json`에 확인 대상으로 기록합니다. 이 검사로 자동 유료 재생성을 실행하지 않습니다.

### Codex 제작 연결

화면 맨 위의 **Codex로 제작하기**를 누르면 정보형·민담 채널 모두 대본과 이미지를 Codex로 만들고, KIE는 선택된 대본의 앞 5장면만 영상으로 변환합니다. 일본어 정보형도 같은 정보형 프로필과 고정 레퍼런스를 사용합니다. 영상 변환 수는 5장면을 넘길 수 없습니다. 주제를 넣어 제작을 시작한 다음 **Codex 요청문 복사**를 눌러 같은 프로그램 폴더를 읽을 수 있는 Codex 대화에 전달하세요. 화면을 열어 두면 결과를 받아 다음 단계를 준비합니다. KIE 영상 변환에는 별도 크레딧이 사용됩니다. 처음 설정에서 대본 AI와 이미지 모드를 각각 바꾸면 기존 KIE 이미지 제작으로 돌아갈 수 있습니다.

이 프로그램이 Codex 대화를 자동으로 시작하거나 내장 도구를 외부 API처럼 호출하지는 않습니다. Codex가 `codex_bridge.py`의 `next`로 요청을 읽고, 결과 TXT/이미지 파일을 `complete`로 등록합니다. 등록에는 현재 요청의 ID와 토큰이 필요합니다. 중단·재실행·초기화한 요청의 이전 결과는 거부하며 완성된 장면은 이어 만들기에서 건너뜁니다. 텍스트는 기존 채널·언어·분량·형식 검사를 거치며 이미지·썸네일은 기존 저장 규칙과 합성기를 사용합니다.

Codex 내장 이미지 도구가 없는 환경이나 계정 한도에 막히면 도우미의 `fail`로 중단합니다. 자동으로 유료 대본·이미지 API를 호출하지 않습니다. Codex 계정 사용량은 별도로 적용되고, 인월드 선택 시 음성 제작과 KIE 영상 변환에는 제공사 비용이 발생합니다. 모의 검증에는 실제 이미지 생성이나 유료 음성 호출을 포함하지 않습니다.

도우미 예: `python codex_bridge.py --root "프로그램 폴더" next` → 결과 작성 → `python codex_bridge.py --root "프로그램 폴더" complete --id 요청번호 --token 현재토큰 --source "결과파일"`. 상태 확인은 `status`, 도구 실패는 `fail --id 요청번호 --token 현재토큰`입니다. 사용자에게 터미널 입력을 요구하지 않고 요청문을 받은 Codex가 실행합니다. 도우미와 편집기 연결 모듈은 배포 구성에 포함됩니다.

제작 중 Codex 전환을 예약하면 현재 영상이 성공적으로 완성되고 대기열이 멈춘 뒤에만 설정을 바꿉니다. 실패 시에는 복구 완료까지 기다리고, 취소·채널 변경 시에는 예약을 취소합니다. 예약은 로컬 설정 전환용 보조 프로그램이 처리하며 AI 호출이나 유료 생성을 실행하지 않습니다.

### 로컬 음성 복제와 바탕화면 저장

설정 → 나레이션에서 한국어·일본어를 각각 인월드 또는 로컬 복제로 선택합니다. 로컬 복제에는 채널별 녹음 파일과 실제 읽은 문장이 필요합니다. 녹음은 3~60초, 10MB 이하이며 약 30초를 권장합니다. 녹음 대본은 `지침/음성복제_녹음대본.txt`와 화면에서 제공합니다. 개인 녹음·모델·실행 환경은 GitHub나 배포에 포함하지 않습니다.

공식 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)의 0.6B Base 모델을 사용합니다. Python 3.12/3.13으로 `로컬음성_설치.py`를 실행하면 별도 환경 `.local-voice`에 패키지와 공식 모델을 설치합니다. 설치에 인터넷이 필요하며 설치 후 생성은 오프라인입니다. 한국어·일본어별 녹음과 낭독 대본은 `로컬음성`에만 저장합니다. 로컬 생성은 API 크레딧을 사용하지 않으며 실패해도 인월드로 자동 전환하지 않습니다.

CPU에서 짧은 자막 구간별로 음성을 생성하고 실제 길이를 측정해 자막·문장별 플로우를 연결합니다. 문자별 강제 정렬은 아니며, 짧게 나누는 특성상 억양이 끊길 수 있습니다. 완료된 조각은 이어 만들기에서 재사용하고 중단 시 실행 중인 로컬 프로세스를 종료합니다. 현재 PC의 AMD Athlon 3000G / 약 14GB RAM에서는 긴 나레이션 생성에 상당한 시간이 걸릴 수 있습니다. 실제 복제 품질은 사용자 녹음을 등록한 후 확인해야 합니다.

최종 렌더는 기존 작업 폴더와 업로드 폴더를 유지하고 `바탕화면/영상/채널명`에도 완성 MP4를 저장합니다. 파일명에는 대본 경로 해시를 붙여 서로 다른 작업의 덮어쓰기를 막습니다. 같은 작업을 다시 렌더하면 해당 영상만 교체합니다.

# 유튜브 주제·대본 자동화

Windows에서 `유튜브_자동화_시작.vbs`를 더블클릭하면 콘솔 창 없이 크롬에서 대본 만들기 화면이 열립니다. 처음 실행에는 필요한 Python 패키지를 설치하느라 시간이 걸릴 수 있습니다. 실행 오류는 `로그_시작.txt`, 대본 화면 오류는 `로그_대본선택.txt`에서 확인하세요.

콘솔에서 실행 과정과 종료 버튼을 보고 싶다면 `유튜브_자동화_시작.bat`를 사용하세요. 영상 편집프로그램은 이 폴더, 상위 폴더, 다운로드, 바탕화면의 `편집프로그램/app.py`를 찾습니다. 다른 곳에 있다면 `YOUTUBE_EDITOR_DIR` 환경 변수에 해당 폴더를 지정하세요.

새 컴퓨터에서는 `설정.example.json`을 `설정.json`으로 복사하고, 열린 화면의 **처음 설정** 탭에서 필요한 키와 목소리를 저장하세요. `설정.json`에는 API 키가 들어가므로 GitHub에 올리지 마세요. `.gitignore`가 이 파일과 생성 결과물을 제외합니다.
